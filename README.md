## 🔭 Focus

- **机器人系统**：ROS2 节点开发、话题与服务通信、参数配置、部署调试，以及坐标系和导航链路验证
- **嵌入式控制**：基于 ESP32-S3 开发 BLE 设备控制、触控界面、传感器交互与多路输出管理
- **视觉与感知**：YOLO / ResNet 模型训练、部署和推理优化，参与智能车视觉感知与障碍物识别
- **工程自动化**：将 CATIA 产品数据、截图、BOM 与客户 Excel 模板串成自动化处理流程
